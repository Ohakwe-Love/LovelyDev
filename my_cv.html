Solarionis Renewable Energy Investment Platform
React, Laravel, PHP, MySQL, JavaScript, Tailwind CSS, Laravel Sanctum, Rest Api
Solarionis is a full-stack investment platform built for renewable-energy investment products. The platform combines a React frontend with a Laravel API to manage user accounts, KYC verification, wallet funding, investments, withdrawals, referral bonuses, and administrative operations. The system also implements a ledger-based accounting architecture and integrates cryptocurrency payments through NOWPayments.

Case Study

  • Problem: A digital investment platform needs to securely coordinate users, investment products, wallet balances, financial transactions, KYC verification, payments, withdrawals, and administrative operations without losing track of how funds move through the system.
  • Approach: I worked on the platform as a complete full-stack system, separating the React frontend from the Laravel API while structuring the backend around clear financial workflows and business rules.
  • Financial Architecture: The platform uses wallet accounts and a ledger-based accounting system. User balances are separated into pending, available, invested, and hold buckets, while financial activity is recorded through ledger transactions and entries.
  • Payment Processing: Implemented a cryptocurrency deposit workflow using NOWPayments, including signed IPN webhook validation and queued webhook processing before crediting user wallets.
  • Investment Logic: Built investment workflows that validate KYC status, investment limits, minimum amounts, share-price requirements, wallet balances, project funding, and referral bonuses before completing an investment.
  • Administration: Developed functionality for administrators to manage deposits, withdrawals, investments, projects, users, KYC reviews, content, ledger activity, and the platform treasury.
  • Key Learning: This project significantly strengthened my understanding of backend architecture, financial workflows, relational databases, API design, authentication, third-party integrations, asynchronous processing, accounting principles, and building systems where data consistency and auditability are critical.

Features

  • React-based public website, user dashboard, and admin dashboard
  • Laravel REST API with Laravel Sanctum authentication
  • User registration, authentication, and email verification
  • Admin authentication with optional MFA
  • Multi-bucket wallet system for pending, available, invested, and held funds
  • Ledger-based accounting with balanced debit and credit entries
  • Cryptocurrency deposits through NOWPayments
  • Signed payment webhook validation and queue-based processing
  • Manual Western Union deposit submission and admin approval workflow
  • Investment management and project funding logic
  • KYC verification and manual administrative review
  • Referral bonus system linked to investments
  • Withdrawal requests with hold, processing, sent, and failed states
  • Platform treasury/admin wallet management
  • Comprehensive admin user and financial management tools
  • Responsive admin tables with mobile card layouts
  • Automated backend tests for important payment and wallet flows
